## Behavioral explanation
Fires the **room-enter PREPARE** transaction. It arms the request flag `0x7005ad = 1`, reserves a txn slot, builds the app-command-registry entry with selector **0xd3**, and sends a reliable SN@P **op0c PREPARE** carrying the pre-built request block at **`0x7004d0`** (the same block assembled by `room_enter_commit_sm` 0x5c3490). Returns the txn slot index, -1 if the table is full.
