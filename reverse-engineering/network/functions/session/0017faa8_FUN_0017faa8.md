## Behavioral explanation
Asynchronous sceDbcMan **bulk send on data channel 3, function 0x8000131c** — the larger-payload twin
of `dbcman_send_data2`. Dedicated client-data `0x27afd8` (its own IOP RPC server), buffer `0x27c380`
(`0x2090` bytes) carrying up to `0x2080` payload bytes. Copies the payload, checks the channel isn't
busy, then fires the async RPC forwarding the caller's completion callback (`param_5`) so the EE learns
when the DMA finishes. Semaphore-guarded around the buffer fill.
