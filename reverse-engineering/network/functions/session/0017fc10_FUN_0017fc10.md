## Behavioral explanation
Synchronous sceDbcMan **control/receive RPC, function 0x8000131a** on the main channel — a
request→response that carries a variable-length payload *back* from the IOP. The caller supplies two
argument words plus an in/out length; the IOP returns a status code at `+0x20c` and, on success, an
updated length at `+0x08` and up to that many payload bytes starting at `+0x0c`, which are copied out
to the caller's buffer. Used by `dbcsock_poll` (FUN_0017e900) to pull an event/datagram off an
endpoint. Not semaphore-guarded (the poll caller runs single-threaded).

- `param_1`, `param_2` (`undefined4`) — request words (endpoint handle / selector) -> `+0x00`,`+0x04`.
- `param_3` (`int *`) — in/out length; in = bytes offered, out = bytes returned.
- `param_4` (`int`) — output buffer base (receives the returned payload).
- Returns `int` = `iRam0027b20c` (IOP status: `>=0` ok, `<0` error); `0` on RPC transport failure.
