## Behavioral explanation
One-time initialiser for the **sceDbcMan** (DNAS broadband connection manager) EE-side client.
Idempotent via `ram0x0022f590`. It initialises the SIF RPC subsystem, then **binds three IOP RPC
servers**: the main control channel `0x80001300` (client-data `0x27af88`), the SendData2 bulk channel
`0x8000131b` (`0x27afb0`), and the SendData3 bulk channel `0x8000131c` (`0x27afd8`). Each bind is
retried in a busy-spin loop until that channel's async-ready word latches. Once all three are bound it
queries the IOP module version (FUN_0017ee08) and **requires major version 3** (`(ver>>8)==3`) or
aborts. It then creates a counting semaphore (max 0x7f, init 1) that serialises the shared RPC
scratch buffers, zeroes the 16-entry socket-flag mirror, logs the banner, performs the initial config
RPC (FUN_0017f0e8 → fn 0x304) against flag table `0x27e480`, and latches `ram0x0022f590 = 1`.

## Input / output

- Returns `undefined4`: `1` = initialised (or already up), `0` = failure at any bind / version /
  semaphore step.
