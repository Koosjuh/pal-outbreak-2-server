## Behavioral explanation
Linear **scan/lookup** over a contiguous region of candidate pointers. Starting at `param_1` and stepping forward `param_2` times (stride 1 byte per the pointer arithmetic — i.e. it probes each successive address), it tests every candidate against a **1-byte tag** (`0x258948`) and the **8-byte record magic** (`0x2588d0`, the same signature emitted by `build_tagged_record` 0x0017c6b8). On a match it writes the matching pointer to `*param_3` and a derived value (`record_value(ptr)`) to `*param_4`. The loop does **not** break on first match, so it returns the **last** matching entry in the range. Out-params are pre-cleared, so "not found" yields `*param_3 = *param_4 = 0`.

## Input / output
- `param_1` : `int` base address / first candidate.
- `param_2` : `int` count of candidates to probe (must be `> 0`).
- `param_3` : `int*` out — matched record pointer (0 if none).
- `param_4` : `u32*` out — `record_value(match)` (0 if none).
- **return** : void (results via out-params).

## Important branches
- guard: `param_1 != 0 && param_2 > 0` — else both outs stay 0.
- per candidate `p`: `tag_match(p, 0x258948, 1) == 0` **and** `tag_match(p, 0x2588d0, 8) == 0` → record `*param_3 = p`, `*param_4 = record_value(p)`.
- no early break → last match wins; `p++`, `count--` until `count == 0`.

## Constants & flags
- `0x258948` — 1-byte discriminator tag.
- `0x2588d0` — 8-byte record magic (shared with the builder 0x0017c6b8).
- match convention: `tag_match == 0` means equal (memcmp-style).

## Corrected reconstruction
```c
// Scan [base, base+count) for a record matching a 1-byte tag AND the 8-byte magic.
// Returns the LAST match (no early break) via out-params; (0,0) if none.
void find_tagged_record(char *base, int count, int *out_ptr, u32 *out_val)
{
    *out_val = 0;
    *out_ptr = 0;
    if (base != NULL && count > 0) {
        do {
            if (tag_match(base, TAG_DISC1 /*0x258948*/, 1) == 0 &&
                tag_match(base, TAG_MAGIC8 /*0x2588d0*/, 8) == 0) {
                *out_ptr = (int)base;
                *out_val = record_value(base);          // FUN_0017c9e8
            }
            count--;
            base++;
        } while (count != 0);
    }
}
```
