## Behavioral explanation

handshake" call issued once at init. It writes the single argument (the EE-side config/flag-table
token `param_1`) into the RPC send scratch at `+0x04` and calls the IOP, which fills the reply word at
`+0x00`. Returns that reply word (a status/handle). On RPC transport failure it logs and returns 0.
