## Behavioral explanation
Synchronous sceDbcMan **bind/activate-endpoint RPC, function 0x80001303**, with a link-state guard.
It first takes a consistent **snapshot** of the 16-entry per-socket flag table `0x27e480` → `0x27e500`
inside a critical section (interrupts disabled around the copy), because the IOP updates `0x27e480`
asynchronously. It then checks the snapshot entry for socket index `param_1`: if that flag is not `1`
(endpoint not open/ready), it returns error `0xfffffff4` without calling the IOP. Otherwise it issues
fn 0x80001303 and returns the IOP-supplied bind handle from scratch `+0x04`.

## Input / output
- `param_1` (`int`) — socket index (0..15) into the flag table.
- Returns `undefined4`: the bind handle (`uRam0027b004`) on success; `0xfffffff4` if the socket flag
  isn't 1; `0` on RPC transport failure.

## Side effects
- Snapshots 8 qwords (`0x40` bytes) `0x27e480` -> `0x27e500` under a disable/enable-interrupt bracket.
- `iRam0027b000 = param_1`; `sif_rpc_call(0x27af88, 0x80001303, sync, …)`.

## Important branches
- `snapshot_flags[param_1] != 1` -> return `0xfffffff4` (endpoint not ready; no RPC issued).
- Flag == 1 and `sif_rpc_call < 0` -> log `0x258ab8`, return 0.
- Flag == 1 and RPC ok -> return `uRam0027b004`.

## Constants & flags
- `0x80001303` = dbcman fn BIND.
- `0xfffffff4` (-12) = "endpoint not ready / invalid state" (same code dbcsock/open uses for bad args).
- Flag table stride = 4 bytes, 16 entries; active value = `1`.
