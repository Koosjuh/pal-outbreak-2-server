## Behavioral explanation

descriptor (a 5-word header + a 16-byte address/id, plus two extra parameters) into the main-channel
send scratch and calls the IOP, which returns the new endpoint handle at scratch `+0x24`. Guarded by
the `ram0x0022f590` init flag (returns 0 if the library was never initialised).
