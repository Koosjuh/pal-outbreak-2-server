## Behavioral explanation
SN@P transport RPC stub for opcode **0x27** — a parameterless command. It sends an empty request (only
the 0x20-byte header) and returns the IOP status word. Its wrapper `FUN_001eedc0` sets mode flag
`0x37a2a2 := 1` after a successful call; opcode **0x28** (`snap_rpc_op28_mode_off`, FUN_001f06a0) is the
counterpart that clears it. So 0x27/0x28 form an **enable/disable pair** for one IOP-side mode.

// Wrapper FUN_001eedc0 sets g_mode_a2a2 = 1 afterward; op28 clears it.
u16 snap_rpc_op27_mode_on(void)
{
