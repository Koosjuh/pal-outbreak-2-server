## Behavioral explanation
**Local-only** setter: writes a small enum (`0..2`) into the device control block at offset +0x08 for
`index`. Bounds-checked against device count and a value ceiling of 2 — same shape as the +0x04 flag
setter (0x1f2728) but a 3-value domain. Corresponds to the `init2` field that `iopdev_rpc_init`
initializes to 1 (and which the init loop stores partly as a u16).

## Input / output
- `param_1` — device index (must be `< g_iopdev_count`).
- `param_2` — value, must be `<= 2` (0/1/2); stored at +0x08.
- **Returns** `u32`: `0` on success, `-0xb` (0xfffffff5) if index OOB, `-0xc` (0xfffffff4) if value > 2.

## Side effects
- `table[index].field8 = (int)param_2` (+0x08).

## Important branches
- `index >= g_iopdev_count` -> return -0xb.
- `param_2 > 2` -> return -0xc.
- else -> write, return 0.

## Constants & flags
- Field offset +0x08. Value domain `{0,1,2}`. `-0xb`/`-0xc` = subsystem OOB/invalid-value codes.
