## Behavioral explanation
A LZSS-style decompressor operating on **16-bit half-words**. It reads a control bit-stream (MSB-first
from 16-bit control words) that selects, per token, between a literal half-word copy and a
back-reference (or a zero-fill run). Output is written half-word by half-word to `param_2`.

Token grammar (each control bit consumed MSB-first from the current 16-bit control word; a fresh
control word is fetched, and the source pointer advanced, whenever the bit mask `uVar4` reaches 0):
- **control bit == 0** → copy one literal half-word: `*dst++ = *src++`.
- **control bit == 1** → back-reference / run:
  - Read a match word `w = *src`. The **length** high field is `w >> 0xB` (top 5 bits); if that is
    `0`, the length is taken from the *next* half-word instead (`len = src[1]`, advance src by 2),
    otherwise `len = w >> 0xB` and the **offset** is `w & 0x7FF` (low 11 bits), advance src by 1.
  - If `offset != 0` → copy `len` half-words from `dst - offset` (a self-overlapping back-copy,
    sliding-window LZ).
  - If `offset == 0` → this is the **zero-fill / RLE-zero** case: write `len` zero half-words. This
    also serves as the termination path — after a zero-fill token with the outer-loop condition, the
    routine exits (the `if (uVar3 == 0) break;` guards the two nested loops).

## Important branches
- `uVar4 == 0` → refill: load next control word into `uVar5`, reset mask `uVar4 = 0x8000`, advance
  `param_1`. (Control bits are consumed via `uVar4 >>= 1` each token; `uVar1 = uVar5 & uVar4`.)
- `control bit == 0` → literal copy, continue inner loop.
- `control bit == 1` → decode match: `uVar3 = w >> 0xB`; if `== 0` take extended length `src[1]`
  (advance 2), else `uVar1 = w & 0x7FF` and advance 1.
- `offset (uVar1) != 0` → back-copy `len` half-words from `dst-offset`.
- `offset == 0` → break to the zero-fill loop: emit `len` zeros; then `if (uVar3 == 0) break` exits.

## Constants & flags
- Control word width 16 bits, MSB-first (`0x8000` initial mask).
- Match word bit split: **length** = bits 11..15 (`w >> 0xB`, 5-bit, `0` ⇒ extended length in next
  half-word); **offset** = bits 0..10 (`w & 0x7FF`, 11-bit ⇒ window up to 2047 half-words back).
- `offset == 0` sentinel = zero-fill run / stream terminator.

## Corrected reconstruction
```c
// LZSS-style half-word decompressor. Control bits MSB-first; matches are 5-bit len / 11-bit offset,
// with len==0 escaping to an extended length half-word, and offset==0 meaning a zero-fill/terminate.
void lz_decompress_halfwords(const u16 *src /*p1*/, u16 *dst /*p2*/)
{
    u32 ctrl = 0, mask = 0;
    for (;;) {
        u32 len;
        for (;;) {
            for (;;) {
                u32 bit = ctrl & mask;
                if (mask == 0) {                 // refill control word
                    ctrl = (u16)*src++;
                    mask = 0x8000;
                    bit  = ctrl & 0x8000;
                }
                mask >>= 1;
                if (bit != 0) break;             // 1 => match/run
                *dst++ = *src++;                 // 0 => literal half-word
            }
            u32 w   = *src;
            u32 off = w;
            len = w >> 11;                       // 5-bit length field
            if (len == 0) { len = src[1]; src += 2; }  // extended length
            else          { off = w & 0x7FF; src += 1; } // 11-bit offset
            if (off == 0) break;                 // zero-fill / terminate
            const u16 *win = dst - off;          // back-reference
            do { len--; *dst++ = *win++; } while (len != 0);
        }
        if (len == 0) break;                     // terminator (len==0 after off==0)
        do { *dst++ = 0; len--; } while (len != 0); // zero-fill run
    }
}
```
> The three nested loops and the `if (uVar3 == 0) break` exits are preserved exactly; variable names
> follow the decompiler's `uVar5=ctrl`, `uVar4=mask`, `uVar1=bit/offset`, `uVar3=len`.
