marshalled; it performs the blocking round-trip (send 0x20 / recv 0x20) and returns the u16 reply
status. This is the "trigger an IOP-side action / read a state with no key" shape (compare fno 0x39
and 0x53, which are also zero-arg commands). Likely a lifecycle or refresh trigger.
