## Behavioral explanation
Producer for a 32-entry command ring at `0x29b000` (stride `0xc`). It writes into the slot at the
current index `uRam0029afe8`, but only if that slot is **free** — the slot's first word acts as a
"empty/full" flag where a **negative** value means free. On success it packs a command word from the
low byte of `param_1` and advances the index modulo 32; on a full slot it returns `-1` without
writing.

The packed word is `0x4A000000 | (sign_extend8(param_1 & 0xff) << 16)` — i.e. tag byte `0x4A` in the
top byte and the (sign-extended) 8-bit payload in bits 16..23. The `<<0x28 >> 0x28` shift pair in the
decompile is an 8-bit sign-extension of the payload before it is shifted into place. Because the
resulting word has bit31 set (`0x4A......` → 0x4A < 0x80, so top bit is 0) — note the stored value is
**positive**, which is how a consumer distinguishes a written slot from the negative "free" sentinel.

## Input / output
- `param_1` (uint) — payload; only the low 8 bits are used (sign-extended into the command word).
- Returns `undefined4`: `0` = enqueued; `0xffffffff` (`-1`) = ring slot busy (full), nothing written.

## Side effects
- Writes the packed command word to `ring[index].word0` (`*(0x29b000 + index*0xc)`).
- Advances `uRam0029afe8 = (index + 1) & 0x1f` (with a redundant negative-wrap correction).

## Important branches
- `(int)*slot < 0` (slot free) → write word, advance index, return 0.
- else (slot's word0 ≥ 0, still occupied) → return `-1`.
- Post-increment: `uVar2 = index+1; uRam0029afe8 = uVar2 & 0x1f;` then
  `if ((int)uVar2 < 0 && uRam0029afe8 != 0) uRam0029afe8 -= 0x20;` — a defensive wrap that is inert
  for the normal `0..31` range.

## Constants & flags
- `0x29b000` — ring base; stride `0xc` (12 bytes/slot); `0x1f` mask ⇒ **32 slots**.
- `0x4A000000` — command tag in bits 24..31 (`0x4A`); payload occupies bits 16..23.
- slot free sentinel: `word0 < 0` (negative) means empty; a stored (positive) word means occupied.
