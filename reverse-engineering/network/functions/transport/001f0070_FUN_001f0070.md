## Behavioral explanation
EE-side **inbound SN@P event pump**. This is the mechanism by which the game (EE) receives asynchronous
lobby/room events (join/leave/list/chat notifications) produced by the SN@P library running on the IOP.

The reply from RPC selector `0x1b` is a **batch** of variable-length event records (up to `0x1030`
bytes) placed at `0x37bf1c`. The function maintains a local staging queue at `0x37aee8` with a drain
cursor `DAT_0024e400`:
- When the cursor is at the base (`== 0x37aee8`), the staging queue is empty, so it issues the RPC to
  refill it. On success (`status == 0`) it copies every record from the reply into the staging queue,
  appends a `-1` terminator, and rewinds the cursor.
- It then pops one record: if the record slot holds the `-1` terminator, the queue is empty and it
  returns `0xffff` (no event). Otherwise it emits the record's fields to the out-params and copies the
  payload to the caller's buffer, then advances the cursor past the record.

### Event record layout (shorts)
| off | field | out-param |
|---|---|---|
| [0] (u16) | opcode / event type | `param_1` |
| [1] (u16) | payload length | `param_2` |
| [2] (u16) | subtype / flags | `param_4` |
| [3] (u16) | pad count (record 16-byte alignment) | — (used only for stride) |
| [4] (u32 @ +0x8) | id / handle | `param_3` |
| [+0xc ..] | payload (`len` bytes) | copied to `param_5` |

Record stride = `len + 0xc + pad`.

## Input / output
- **param_1** (`s16*` out): event opcode/type.
- **param_2** (`s16*` out): payload length.
- **param_3** (`u32*` out): id / handle.
- **param_4** (`s16*` out): subtype/flags.
- **param_5** (buffer out): receives `len` payload bytes.
- **Return** (`u16`): `0` = event delivered; `0xffff` = queue empty (no event).

## Side effects
- WaitSema/SignalSema around the whole body (serializes RPC access).
- Issues `sceSifCallRpc` selector `0x1b` (only when staging is empty) — reads from the IOP SN@P module.
- Refills local staging `0x37aee8`, writes `-1` terminator, mutates `DAT_0024e400`.
- memcpy into caller's `param_5`.

## Important branches
- `DAT_0024e400 == 0x37aee8` (staging empty) → refill via RPC; `status(0x37bf18) == 0` gates the copy
  loop that drains reply records into staging (loop terminates on record header `== -1`).
- After refill, `*DAT_0024e400 == -1` (still empty) → return `0xffff`, rewind cursor.
- else → emit one record, advance cursor by `len + 0xc + pad`, return `0`.

## Constants & flags
- `0x1b` = SN@P IOP-module RPC selector (poll/receive events).
- `0x37cf00` req base (len `0x20`), `0x37bf00` reply base (len `0x1030`, batch buffer).
- `0x37bf18` = RPC status word (`0` = OK). `0x37bf1c` = reply payload / first record.
- `0x37aee8` = local staging-queue base; `-1` (`0xffff`) = record terminator / "empty".
- Record header stride constant `0xc` (12-byte header before payload).

```c
// SN@P inbound event pump — poll one async lobby/room event from the IOP SN@P module.
// RPC selector 0x1b; batch reply drained through a local staging queue @ 0x37aee8.
#define SNAP_STAGING_BASE  0x37aee8
#define SNAP_RPC_REQ       0x37cf00
#define SNAP_RPC_REPLY     0x37bf00
#define SNAP_RPC_STATUS  (*(s16*)0x37bf18)

typedef struct snap_evt_hdr {   // [inferred] all u16 except id
    u16 opcode;     // [0]
    u16 len;        // [1]  payload byte count
    u16 subtype;    // [2]
    u16 pad;        // [3]  padding for 16B stride
    u32 id;         // [4]  (+0x8) handle/id
    /* payload[len] at +0xc */
} snap_evt_hdr;

u16 snap_rpc_poll_event(s16 *opcode, s16 *len, u32 *id, s16 *subtype, void *payload_out)
{
    snap_rpc_lock();                                   // FUN_001ef3e0 WaitSema

    if (g_stage_cursor == (s16*)SNAP_STAGING_BASE) {   // DAT_0024e400: staging empty -> refill
        snap_rpc_call(0x1b, SNAP_RPC_REQ, 0x20, SNAP_RPC_REPLY, 0x1030);   // FUN_001ef400
        if (SNAP_RPC_STATUS == 0) {
            s16 *r = (s16*)0x37bf1c;                   // reply records
            for (; *r != -1; r = (s16*)((int)r + stride(r)))
                memcpy(g_stage_cursor, r, stride(r)),  // FUN_001069a8
                g_stage_cursor = (s16*)((int)g_stage_cursor + stride(r));
        }
        *g_stage_cursor = -1;                          // terminate staging
        g_stage_cursor  = (s16*)SNAP_STAGING_BASE;     // rewind for popping
    }

    snap_evt_hdr *e = (snap_evt_hdr *)g_stage_cursor;
    u16 rc;
    if (*(s16*)e == -1) {                              // queue empty
        rc = 0xffff;
        g_stage_cursor = (s16*)SNAP_STAGING_BASE;
    } else {
        *opcode  = e->opcode;
        *len     = e->len;
        *id      = e->id;
        *subtype = e->subtype;
        memcpy(payload_out, (char*)e + 0xc, e->len);   // FUN_001069a8
        g_stage_cursor = (s16*)((int)e + e->len + 0xc + e->pad);
        rc = 0;
    }

    snap_rpc_unlock();                                 // FUN_001ef3f0 SignalSema
    return rc;
}
// stride(r) = r[1] + 0xc + (u16)r[3]
```

## Notes / uncertainty
