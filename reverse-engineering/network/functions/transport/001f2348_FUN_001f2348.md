## Behavioral explanation

and a bounds check (`index < g_iopdev_count`). Writes the index byte to the send buffer (0x37ea40),
takes the semaphore, calls `sceSifCallRpc` async-mode 1 (send 0x10 / recv 0x50, cb 0x1f2868), and
records pending op 2 with the saved index and result pointer. Returns 0 on dispatch, -0xb on bad index,
-2 on RPC error, -1 if uninitialized.
