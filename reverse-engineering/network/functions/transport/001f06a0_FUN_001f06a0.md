## Behavioral explanation
SN@P transport RPC stub for opcode **0x28** — parameterless command, the **disable** counterpart of
opcode 0x27 (`snap_rpc_op27_mode_on`, FUN_001f0650). Its wrapper `FUN_001eef80` clears mode flag
`0x37a2a2 := 0` after the call. Note this is the *transport-layer* fno 0x28 (an IOP room-op), distinct
from the SN@P *app* opcode 0x28 (op28 selector reply on the wire) — same numeric byte, different space.

## Corrected reconstruction
```c
// SN@P transport RPC stub — opcode 0x28: parameterless "disable mode" command (pair of op27).
// Wrapper FUN_001eef80 clears g_mode_a2a2 = 0 afterward.
u16 snap_rpc_op28_mode_off(void)
{
    snap_ipc_lock();                                       // WaitSema(0x37aee0)
    snap_ipc_call_rpc(0x28, SEND_A, 0x20, RECV_B, 0x20);   // header-only round trip
    u16 status = *(u16*)(RECV_B + 0x18);                   // 0x37bf18
    snap_ipc_unlock();                                     // SignalSema(0x37aee0)
    return status;
}
```
