## Behavioral explanation
Extracts a **fixed 18-word (0x48-byte) configuration block** from the tagged-record tree, with a magic
validation. Steps:
1. Resolve container node via `FUN_00199f70(param_2,param_3)`; require `node->type == 4` else return
   `-1`.
2. Find-or-load the child record for tag `0xf0000` (`FUN_0019a350(node, 0xf0000, 0)`); if absent
   return `-1`.
3. Read the record's first payload word (`+0x0c`) into `out[0]` and **validate its high half-word ==
   `0x0001`** (`(word & 0xffff0000) == 0x10000`). This is a version/format magic. If it fails, return
   `-2` (`0xfffffffe`) — record present but wrong format.
4. On magic-OK, copy 18 consecutive u32 words (`record+0xc .. record+0x50`) into `out[0..17]` and
   return `0`.

The 18-word block with a `0x0001____` magic in word 0 is the shape of a fixed network-config
descriptor (e.g. an interface/address/DNAS settings block: several IP-like u32 fields + flags).

## Input / output
- **Param 1** (`param_1`, `uint*`): output buffer receiving 18 u32 words on success.
- **Param 2, Param 3**: container-node selector.
- **Return:** `undefined4` —
  - `0` success (18 words written),
  - `0xffffffff` (`-1`) node not type 4, or tag `0xf0000` record missing,
  - `0xfffffffe` (`-2`) record present but word0 magic high-half ≠ `0x0001` (only `out[0]` written).

## Important branches
- `if (*(int*)node != 4) return -1;`
- `if (record == 0) return -1;`
- `*param_1 = payload[0]; if ((*param_1 & 0xffff0000) == 0x10000) { copy 18 words; return 0; } else
  return -2;` — magic gate distinguishes "missing" (-1) from "malformed" (-2).

## Constants & flags
- `4` — required container-node type.
- `0xf0000` — TLV tag selecting the config-block record.
- `0x00010000` mask/`0x10000` value — word-0 format/version magic (high half-word must be `1`).
- Block size `0x48` bytes = 18 u32 (`+0x0c .. +0x50`).
- Returns: `0` ok, `-1` missing, `-2` bad magic.

## Corrected reconstruction
```c
#define NODE_TYPE_CONTAINER 4
#define TLV_TAG_CFGBLOCK    0xf0000
#define CFGBLOCK_MAGIC_HI   0x00010000   // (word0 & 0xffff0000) must equal this

int tlv_read_config_block_tagf0000(u32 *out, node_sel a, node_sel b)
{
    struct tlv_node *node = tree_resolve(a, b);           // FUN_00199f70
    if (node->type != NODE_TYPE_CONTAINER)
        return -1;

    struct tlv_record *r = node_find_or_load(node, TLV_TAG_CFGBLOCK, 0); // FUN_0019a350
    if (r == NULL)
        return -1;

    out[0] = r->payload[0];                               // *(u32*)(r+0xc)
    if ((out[0] & 0xffff0000) != CFGBLOCK_MAGIC_HI)
        return -2;                                        // 0xfffffffe: wrong format

    for (int i = 0; i < 18; i++)                          // r+0xc .. r+0x50
        out[i] = r->payload[i];
    return 0;
}
```
