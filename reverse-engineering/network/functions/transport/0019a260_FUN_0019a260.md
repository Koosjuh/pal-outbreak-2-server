## Behavioral explanation
Reads an entire fixed-tag resource/section table into a caller-supplied word array. It first
obtains a base handle from `FUN_00199f70()`, then resolves the section identified by tag `0x50000`
via `FUN_0019a350(handle, 0x50000, 0)`. The resolved section has a small header: a `count` at
`+4` and an array of `count` 32-bit entries beginning at `+0xc`. All `count` words are copied
verbatim into `param_3[0..count)`. Returns 1 on success, 0 if either lookup fails.

This is the "copy the whole list" sibling of `FUN_0019a210` (returns only the count) and
`FUN_0019aaf0` (returns one entry). `param_1`/`param_2` are declared but unused here — the function
signature is shared with the family; only the output buffer `param_3` matters.

## Input / output
- `param_1` (undefined8) — **unused** in this variant (present for family ABI compatibility).
- `param_2` (undefined8) — **unused**.
- `param_3` (int, used as base address) — **out**: destination `u32[]`, filled with `count` words.
- Returns `undefined4`: `1` = table copied, `0` = handle or section lookup failed.

## Side effects
- Writes `count` words into `*param_3` (caller buffer). No globals mutated.

## Important branches
- `FUN_00199f70() == 0` → return 0 (no base handle / subsystem not ready).
- `FUN_0019a350(handle,0x50000,0) == 0` → return 0 (section/tag not present).
- Success path: loop `uVar5 = 0 .. count-1`, `param_3[uVar5] = section[0xc + uVar5*4]`; `uVar2` is
  pre-set to 1 each iteration (so an empty table, `count==0`, still returns 1).

## Constants & flags
- `0x50000` — section/tag selector passed to `FUN_0019a350` (same tag used by `FUN_0019a210`).
  [inferred] a resource-section id; not yet mapped to a symbolic name.
- header layout: `+0x04` = entry count (u32); `+0x0c` = first entry (u32 array).

## Corrected reconstruction
```c
// Copy every word of the 0x50000-tagged resource section into out[].
// Returns 1 on success (even for an empty section), 0 if the section is unavailable.
int resource_table_copy_all(void *unused1, void *unused2, u32 *out /*param_3*/)
{
    struct res_section { u32 _pad0; u32 count; u32 _pad8; u32 entries[]; } *sec;

    void *base = FUN_00199f70();                 // open/get table base handle
    if (base == NULL)
        return 0;

    sec = FUN_0019a350(base, 0x50000, 0);        // resolve section by tag
    if (sec == NULL)
        return 0;

    for (u32 i = 0; i < sec->count; i++)         // count @ +4, entries @ +0xc
        out[i] = sec->entries[i];
    return 1;
}
```
