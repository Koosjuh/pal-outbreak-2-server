## Behavioral explanation
Duplicates a variable-length blob referenced by `*(param_1+8)`. The blob's own length is stored at
its offset `+0xc`; the function allocates a new buffer sized to that length (alignment class 4),
resolves the allocation handle to a pointer, and byte-copies the entire blob (from its base) into the
new buffer. Returns the allocation **handle** (not the resolved pointer). This is the "deep-copy the
message body" step — e.g. cloning a received packet/record so it survives past the source buffer.
