## Behavioral explanation
Issues the **set-mode RPC (fno 5)** for a device index. Gated on init and two bounds checks
(`index < count`, `mode < 3`). Mirrors the mode into the local control block (`table[index].mode = mode`)
so EE-side state matches the IOP, packs index+mode into the send buffer (0x37ea40/0x37ea41), takes the
semaphore, calls `sceSifCallRpc` async-mode 1 (send 0x10 / recv 0x10, cb 0x1f2868), and records pending
op 5. Returns 0 on dispatch, -0xc on bad mode, -0xb on bad index, -2 on RPC error, -1 if uninitialized.

- **Returns** `s64`: `0` dispatched, `-0xc` (…fff4) bad mode, `-0xb` (…fff5) bad index, `-2` RPC error,
