## Behavioral explanation
Bounds-checked indexed getter into a TLV record's u32 payload array. Resolves the record for `param_1`
(`FUN_001999f0(param_1,0)`); if it exists and `index < record->count`, returns `payload[index]`
(`*(u32*)(rec + 0xc + index*4)`). Any failure — record not found, or index out of range — returns the
error sentinel `0xffffffff` (`-1`). This is the element accessor paired with `FUN_00199890`
(count-by-key): iterate `0 .. count-1` and read each with this function.

## Input / output
- **Param 1** (`param_1`): record key/selector.
- **Param 2** (`param_2`, `uint`): element index into the payload array.
- **Return:** `undefined4` — `payload[index]` on success; `0xffffffff` if the record is missing or
  `index >= count`.
