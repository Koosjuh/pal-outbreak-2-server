`FUN_00195cf0`; if that returns 0 the whole init is **aborted** returning 0 (nothing is built). On
success it: runs two init calls (`FUN_00111600`, then `FUN_00101f80(1)` to enable/select mode 1),

storing each result at `0x28a2f4 + i*4`, runs a further init (`FUN_0017e3f0`), sets the ready latch
`uRam00289af0 = 1`, and finally **registers a handler**: `FUN_00183350(0x289af0, 0x1000, 0x183680)`
— binding callback `0x183680` to a `0x1000`-byte (4 KiB) region/context at `0x289af0`. Returns 1.

The 10-entry table + 4 KiB region + registered callback is the shape of a device/handler table init
(e.g. binding 10 slots/vectors and installing a dispatch or interrupt/thread handler). `0x1000`
reads naturally as a stack/context/buffer size for the registered handler.
