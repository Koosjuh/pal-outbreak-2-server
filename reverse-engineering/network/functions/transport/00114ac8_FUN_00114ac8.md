## Behavioral explanation
A variadic formatted-output entry point (printf-family). It temporarily installs `FUN_001141b0`
as the active output-sink through the global vector `PTR_FUN_002098c4`, spills its register-passed
variadic arguments (param_2..param_8) into a contiguous stack argument array, and hands both the
format/control argument (param_1) and the argument array to the shared formatter core
`FUN_00114498`. On return it restores the previous sink pointer, so the swap is scoped to this call.

This is the classic MIPS o32/n32 "gather the vararg tail into a stack vector, then call the real
vprintf" shim. The sink swap selects *where* the formatted bytes go (e.g. a specific console/serial
or buffer writer) for the duration of the format.
