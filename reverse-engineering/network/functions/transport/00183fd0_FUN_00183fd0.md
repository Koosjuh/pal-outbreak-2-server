## Behavioral explanation
Builds a filesystem path from a fixed prefix + the caller's name component (`param_1`) + a fixed
suffix, then returns the size of that file by opening it, seeking to end, and closing. It is a
"does this file exist and how big is it" probe (a stat-by-open, since no stat syscall is used). The
open/seek/close is bracketed by a global lock (FUN_00129ff8 / FUN_0012a010) so the shared 2 KB path
scratch and the file layer are used single-threaded.
