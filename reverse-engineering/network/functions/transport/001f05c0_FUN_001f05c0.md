## Behavioral explanation
One member of the SN@P EE→IOP synchronous-RPC stub family. It ships transport opcode **0x25**, a
variable-length payload upload, to the IOP network module. It stages a 16-bit subcode and a 16-bit length
into the shared DMA send buffer, `memcpy`s `len` bytes of caller data after them, then issues the blocking
RPC and returns the IOP status word. The whole exchange is serialized under the single IPC semaphore
(`0x37aee0`) shared by every stub in this family, because the send/recv buffers (`0x37cf00`/`0x37bf00`)
are process-global and reused by all opcodes.

## Input / output
- **param_1** (u16): subcode, written to `A+0x1c`. Sole caller passes `1`.
- **param_2** (u16): payload length in bytes, written to `A+0x1e`; also the `memcpy` count.
- **param_3** (const void*): source of the payload copied to `A+0x20`. Sole caller passes a 4-byte value.
- **Returns** (u16): IOP status word read from `B+0x18` (`0x37bf18`).

## Side effects
- `WaitSema(0x37aee0)` / `SignalSema(0x37aee0)` around the call (mutual exclusion on the shared buffers).
- Overwrites shared send buffer A and shared recv buffer B.
- Blocks until the IOP replies (RPC mode 0).

## Important branches
- No control flow of its own. Size handling (16-byte round-up of ssize `0x124` / rsize `0x20`) happens
  inside `snap_ipc_call_rpc`. Note `param_2` is trusted as the copy length with no bound check here;
  the fixed `ssize=0x124` implies a max payload of `0x104` (260) bytes at `A+0x20`.

## Constants & flags
- Transport fno `0x25`. `ssize=0x124`, `rsize=0x20`. Status at buffer offset `+0x18`.
- Send layout: `{ +0x1c: u16 subcode, +0x1e: u16 len, +0x20: u8[len] payload }`.

## Corrected reconstruction
```c
// SN@P transport RPC stub — opcode 0x25: upload a variable-length payload to the IOP net module.
// snap_ipc_buf A @0x37cf00 (send), B @0x37bf00 (recv); see snap_ipc_call_rpc (0x1ef400).
u16 snap_rpc_op25_put_blob(u16 subcode, u16 len, const void *payload)
{
    snap_ipc_lock();                          // WaitSema(g_ipc_sema /*0x37aee0*/)
    *(u16*)(SEND_A + 0x1c) = subcode;         // 0x37cf1c
    *(u16*)(SEND_A + 0x1e) = len;             // 0x37cf1e
    memcpy((void*)(SEND_A + 0x20), payload, len);   // FUN_001069a8, up to 0x104 bytes
    snap_ipc_call_rpc(0x25, SEND_A, 0x124, RECV_B, 0x20);   // blocking EE->IOP RPC
    u16 status = *(u16*)(RECV_B + 0x18);      // 0x37bf18
    snap_ipc_unlock();                        // SignalSema(0x37aee0)
    return status;
}
```
