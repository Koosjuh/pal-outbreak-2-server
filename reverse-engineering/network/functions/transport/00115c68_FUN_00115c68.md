## Behavioral explanation
EE-side **SIF RPC call** stub (`sceSifCallRpc` shape). Invokes remote RPC function `param_2` on a
previously-bound server, sending input buffer `param_4` (length `param_5`) to the IOP and receiving
results into `param_6` (length `param_7`). It allocates a SIF request node, records the send/receive
buffers and sizes on it, writes back the EE data cache for the DMA'd regions (unless suppressed),
then dispatches SIF command `0x8000000a`. Synchronous mode blocks on a semaphore; async mode records
a completion callback (`param_8`) + user arg (`param_9`) and returns immediately.

## Input / output
- `param_1` (`int *`) — client-data block. Fields written: `[0]`=node, `[1]`=node server-id
  (`node+0x18`), `[2]`=sema (or -1), `[6]`=`&_mips_gp0_value` (callback gp), `[7]`=`param_8`
  (callback fn), `[8]`=`param_9` (callback arg); `[5]` read as the packet-mode word passed to
  dispatch.
- `param_2` — remote RPC function number (`node+0x20`).
- `param_3` (`ulong`) — mode flags. **bit0 = ASYNC**, **bit1 = NO_CACHE_WB** (skip FUN_00115250).
- `param_4` — send buffer (DMA source).  `param_5` — send length.
- `param_6` — receive buffer.            `param_7` — receive length.
- `param_8` — async completion callback fn.  `param_9` — callback user arg.
- Returns `undefined4`: `0` success, `0xFFFFFFFF` alloc fail, `0xFFFFFFFD` sema-create fail,
  `0xFFFFFFFE` dispatch fail.

## Side effects
- Node fields: `+0x14`=self, `+0x1c`=client, `+0x20`=fn, `+0x24`=`param_5`(send len),
  `+0x28`=`param_6`(recv buf), `+0x2c`=`param_7`(recv len), `+0x34`=`param_1[9]`, `+0x30`=busy/mode.
- Data-cache writeback of the send (and, when distinct, receive) regions before DMA.
- Sync path creates/waits/deletes a semaphore.

## Important branches
- `lVar2 == 0` -> return -1.
- `(param_3 & 2) == 0` (cache WB enabled):
  - if `param_4 == param_6` (send buf == recv buf): flush once over `max(param_5, param_7)`.
  - else: flush send region (`param_5>0`) and recv region (`param_7>0`) separately.
- `(param_3 & 1) == 0` (SYNC): CreateSema; if `<0` free node, return -3; set `node+0x30 = 1` (busy);
  dispatch cmd 0xa; if dispatch != 0 -> WaitSema+DeleteSema, return 0; else DeleteSema, fall to fail.
- `(param_3 & 1) != 0` (ASYNC): `node+0x30 = (param_8 != 0) ? 1 : 0`; `param_1[2] = -1`; dispatch; if
  != 0 return 0; else fall to fail.
- Shared fail tail: `FUN_00115570(node)` + return -2.

## Constants & flags
- `0x8000000a` — SIF request selector = **CALL**.
- `0x40` — dispatch mode/priority arg (same as BIND stub 0x00115a98).
- `param_3 & 1` ASYNC; `param_3 & 2` NO_CACHE_WB.
- `node+0x30` — busy/pending flag (1 = a completion is expected).

int sif_rpc_call(sif_client_t *cd, u32 fn, u32 flags,
                 void *sbuf, int slen, void *rbuf, int rlen,
                 sif_cb_t cb, void *cb_arg)     // param_1..param_9
{

    if (node == NULL) return -1;

    cd->cb_arg = cb_arg;                 // param_1[8]
    cd->srv_id = node->server_id;        // param_1[1] = *(node+0x18)
    cd->node   = node;                   // param_1[0]

    node->recv_len  = rlen;              // node+0x2c

    node->cb_arg    = cd->w9;            // node+0x34 = param_1[9]

    if (!(flags & SIF_NO_CACHE_WB)) {                  // FUN_00115250 = dcache writeback
        if (sbuf == rbuf) {
            dcache_wb(sbuf, slen < rlen ? rlen : slen);
        } else {
            if (slen > 0) dcache_wb(sbuf, slen);
            if (rlen > 0) dcache_wb(rbuf, rlen);
