## Behavioral explanation
SN@P IOP-module RPC stub, **selector `0x24`**, no request args. Runs the synchronous RPC (`0x20` send /
`0x4c` recv) and returns a **single reply word** (`0x37bf1c`) via `param_1`, plus the status word as the
return value. It is the "read one scalar" query — same reply buffer size as selector `0x23`
(`FUN_001f04a0`) but only the first word is consumed, so it fetches a single id/handle/count/state value
from the SN@P library.
