## Behavioral explanation
Cold bring-up of the EE-side network-adaptor layer. It (1) clears the driver-state region via
`FUN_001c0230`, (2) resets a pair of state words, (3) registers a set of interface/transport
descriptors through repeated `FUN_001bf380(desc, mode, cfg, 0, 0)` calls, and (4) probes the physical
adaptor with `FUN_0011a660(0x248400)`. A non-negative probe result means the adaptor is present: the
descriptor at `0x35c3b8` is populated from the device table (`DAT_002483c0..cc`, type token `0x21`,

it publishes the active descriptor pointer `uRam0035c3d8 = 0x35c3b8` (consumed later by
