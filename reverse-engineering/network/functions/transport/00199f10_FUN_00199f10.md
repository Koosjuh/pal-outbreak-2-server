## Behavioral explanation
Fetches the scalar value of TLV entry **tag 2** from the root store, with a lazy-load fallback:
1. Get the root/store handle (`FUN_0019a2f0`).
2. Try a search-only lookup of tag `2` (`FUN_0019a300(root, 2)`). **If found** (non-zero), return `0`
   — i.e. this path reports "present" as value 0 and does **not** read the entry's value.
3. **If not found**, do a find-or-load lookup (`FUN_0019a350(root, 2, 0)`). If that also fails, return
   `0`; otherwise return the loaded entry's value word (`+0x04`).

Net effect: returns the value at `+0x04` of tag-2 **only when the entry had to be loaded**; if it was
already resident (search hit) it returns 0. This asymmetry is faithfully preserved from the decompile
— it looks like a "value if freshly loaded, else 0/already-cached" probe (or the search-hit branch is
a decompiler artefact of an unread value). Compare `FUN_0019a010` which is the identical routine for
tag `9`.

## Input / output

- `lVar3 = FUN_0019a300(root, 2); if (lVar3 != 0) return 0;` — already-present ⇒ 0.
- else `lVar3 = FUN_0019a350(root, 2, 0); if (lVar3 == 0) return 0; else return *(u32*)(lVar3+4);`

```c
#define TLV_TAG_2 2

u32 tlv_get_value_tag2(void)
{
    store_handle root = tlv_root();                 // FUN_0019a2f0
    if (tlv_find(root, TLV_TAG_2) != NULL)          // FUN_0019a300 — search only
        return 0;                                   // already resident: report 0

    struct tlv_record *e = tlv_find_or_load(root, TLV_TAG_2, 0); // FUN_0019a350
    if (e == NULL)
        return 0;                                   // load failed
    return e->value;                                // *(u32*)(e+4)
}
```
