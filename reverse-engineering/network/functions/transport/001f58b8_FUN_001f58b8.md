## Behavioral explanation
Initializes an IOP network library over SIF-RPC and performs a **version handshake**. On first entry it creates two semaphores (a mutex `DAT_0024e8ec` init=1, and a signal `DAT_0024e8f0` init=0), runs `netlib_preinit`, then under the mutex binds **service 0x80000400** (client `0x390900`) and issues RPC **fno 0xfe** (a "hello"/query) with a 0x30-byte request and a 0xC-byte reply. The reply is three words: `[0]` = handle/version returned to caller, `[1]` and `[2]` = the library's build/version numbers, which are gated against **minimums 0x20a and 0x20e**. If either is too old it returns a distinct negative error; a too-old library is rejected rather than used.

## Input / output
- (none) : void → `int`.
- **return** : reply word 0 (`iRam00391ec0`, a handle/version) on success; negatives on failure:
  - `rc - 100` if the RPC itself failed (`rc < 0`),
  - `-0x78 (-120)` if `reply[1] < 0x20a`,
  - `-0x79 (-121)` if `reply[2] < 0x20e`.

## Side effects
- One-time: `CreateSema` ×2 into `DAT_0024e8ec` (mutex, init/max=1) and `DAT_0024e8f0` (signal, init=0/max=1).
- `WaitSema/SignalSema(DAT_0024e8ec)` bracketing the RPC.
- Bind-spin service 0x80000400 until ready word `iRam00390924 != 0`; on bind hard-error logs `0x25b670` and **hangs forever** (fatal).
- On version failure clears the ready word (`iRam00390924 = 0`) so a later retry re-binds.

## Important branches
- `DAT_0024e8ec < 0` (semaphores not yet created) → create both.
- bind `sif_rpc_bind < 0` → fatal log + infinite hang.
- `sif_rpc_call < 0` → `iRam00390924 = 0`; return `rc - 100`.
- `reply[1] (iRam00391ec4) < 0x20a` → log `0x25b688`; clear ready; return `-0x78`.
- else `reply[2] (iRam00391ec8) < 0x20e` → log `0x25b6b0`; clear ready; return `-0x79`.
- else → return `reply[0]`.

## Constants & flags
- `0x80000400` — SIF-RPC service id (netlib).
- fno `0xfe` — init/hello query.
- `0x20a` / `0x20e` — minimum version numbers for reply words 1 and 2.
- errors `-100` (RPC), `-0x78` (ver1 too old), `-0x79` (ver2 too old).

```c
// Init an IOP net library (SIF-RPC service 0x80000400) with a version handshake.
int netlib_init_version_gate(void)
{
    if (g_netlib_mutex < 0) {                            // DAT_0024e8ec: first time
        sema_attr a;
        a.init = 1; a.max = 1;  g_netlib_mutex  = CreateSema(&a);  // mutex
        a.init = 0; a.max = 1;  g_netlib_signal = CreateSema(&a);  // signal (DAT_0024e8f0)
    }
    netlib_preinit(0, 0, 0);                             // FUN_001f62c8
    WaitSema(g_netlib_mutex);
    sif_dma_sync(0);

    while (1) {                                          // bind service, wait ready
        if (sif_rpc_bind(&netlib_client, 0x80000400, 0) < 0) {
            net_tracef(FMT_bind_fatal);                 // 0x25b670
            for (;;) {}                                 // hang
        }
        if (netlib_client.server_ready != 0) break;     // iRam00390924
        delay_spin(0x100000);
    }

    long rc = sif_rpc_call(&netlib_client, 0xfe, 0,
                           send/*0x390980*/, 0x30, reply/*0x391ec0*/, 0xC, 0);
    SignalSema(g_netlib_mutex);

    if (rc < 0) {
        netlib_client.server_ready = 0;
        return (int)rc - 100;
    }
    if (reply.ver1 < 0x20a) {                            // iRam00391ec4
        net_tracef(FMT_ver1_old);                       // 0x25b688
        netlib_client.server_ready = 0;
        return -0x78;
    }
    int ret = reply.handle;                              // iRam00391ec0
    if (reply.ver2 < 0x20e) {                            // iRam00391ec8
        net_tracef(FMT_ver2_old);                        // 0x25b6b0
        netlib_client.server_ready = 0;
        return -0x79;
    }
    return ret;
}
```
