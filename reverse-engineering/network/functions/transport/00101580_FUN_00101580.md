## Behavioral explanation
Preferred variant of the single-word control op, on **service 0x8000059c** (same client node `0x25bc50`, own mutex `DAT_002074b0`, own reply buffer `0x208f00`). Structurally identical to `net_rpc_ctl_svc59a` but with a **bounded bind wait**: the bind-readiness spin retries at most ~0x11 (17) times, and if the 0x59c server never signals ready it **releases the mutex and delegates to `net_rpc_ctl_svc59a(param_1)`** (the 0x59a fallback). Returns the reply word, or `6` / `-1`(op 8) on error.
