## Behavioral explanation
Initializes a **second, independent SIF-RPC client** (separate from the SN@P IPC layer of the 0x1f0c40
family): binds to IOP RPC server **0x80000211**, enumerates a set of ≤128 "devices/channels" from the
IOP module, allocates and initializes a per-device control-block table (0x38 bytes each) in EE RAM at
0x37eb10, and installs a VBLANK-end INTC handler that drives asynchronous RPC completion. On any
failure it tears down the semaphore and returns -1.

Sequence:
1. `sceSifInitRpc(0)` (FUN_00115300).
2. Retry loop: `sceSifBindRpc(client=0x37e9e0, server=0x80000211, 0)` (FUN_00115a98); if it returns <0,
   print error 0x25a818 and return -1; spin (busy-wait ~0x10000 iterations) until `iRam0037ea04 != 0`
   (bind-complete flag) — standard SIF bind-wait.
3. `CreateSema` -> DAT_0024e430 (the subsystem mutex + "initialized" guard); -1 => print 0x25a830, return -1.
4. `iopdev_rpc_enumerate(&count_buf)` (FUN_001f22a0, fno 1) then `iopdev_rpc_poll(0,&err)` (FUN_001f27c8)
   to synchronize; require `err==0 && 0 < count < 0x80`.
5. Store `count` -> 0x37e940 and `*param_1`; set table base 0x37e944 = 0x37eb10; init each 0x38-byte
   block (see fields below); clear 0x37e950.
6. `AddIntcHandler(3 /*VBLANK_END*/, 0x1f2f40, -1)` -> 0x37e9dc; if <0, DeleteSema and return -1.
7. `EnableIntc(3)` (FUN_001133e8), return 0.

## Input / output
- `param_1` — out `uint*`; receives the device count on success.
- **Returns** `0` on success, `-1` (0xffffffff) on any bind/sema/enumerate/handler failure.

## Side effects
- Binds SIF client 0x37e9e0 to server 0x80000211.
- Creates the subsystem semaphore DAT_0024e430 (also the init-guard tested by all sibling calls).
- Populates the device table at 0x37eb10 (count * 0x38 bytes) and its metadata (0x37e940 count,
  0x37e944 base, 0x37e950 cursor).
- Installs + enables the VBLANK-end INTC handler FUN_001f2f40 (id saved at 0x37e9dc).
- On failure paths: DeleteSema(DAT_0024e430); DAT_0024e430 = -1.

## Important branches
- `sceSifBindRpc < 0` -> print, return -1.
- `iRam0037ea04 == 0` -> keep spinning (bind not ready).
- `CreateSema == -1` -> print, return -1.
- Enumerate result `err != 0 || count <= 0 || count >= 0x80` -> DeleteSema, return -1.
- `AddIntcHandler < 0` -> DeleteSema, return -1.
- All-pass -> EnableIntc(3), return 0.

## Constants & flags
- `0x80000211` — IOP SIF-RPC server id for this module.
- `3` — INTC cause = **VBLANK_END** (EE INTC map); handler FUN_001f2f40.
- `0x80` (128) — hard cap on device count. `0x38` (56) — per-device control-block stride.
- Per-block init: `[0]=1, [1]=1, [2]=1, [3..7]=0, [8]=(u16)0, [0xb]=0, [0xc]=0, [0xd]=0`
  (word indices; see field-setter siblings 0x1f25e0/0x1f2728/0x1f2778/0x1f26e0).
