## Behavioral explanation
Selects an RGB colour from a 3-byte-per-entry palette table (`DAT_00245400`) by index `param_1`,
caches the components, and programs draw/GS register `0x14` with the packed colour (fixed full alpha).
Used to set a clear/background colour on the asset/display path.

Index scaling: `param_1 *= 3` addresses the R/G/B triple at `DAT_00245400[3*i + 0..2]`. The three
bytes are stashed in `bRam0034321c` (R), `bRam0034321d` (G), `bRam0034321e` (B), then combined into
the register value `B | (R << 16) | 0xFF000000 | (G << 8)` = `0xFF<<24 | R<<16 | G<<8 | B` — i.e.
ARGB with alpha `0xFF`.
