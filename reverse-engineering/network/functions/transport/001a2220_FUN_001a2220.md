## Behavioral explanation
Reboots the IOP and loads a fresh IOP RAM image (the IRX module set that includes the network
stack), relocates it, and starts its modules. Classic PS2 "IOP reload" sequence:
1. **Stop/reset** current SIF/RPC state (`FUN_00115300(0)`, `FUN_00119aa8`, `FUN_001010a8(0)`,
   `FUN_00116cb8`), then spin until the SIFCMD/SIFRPC re-init handshakes complete
   (`do{ FUN_0011af28(0x244ed0) }while(0)`, `do{ FUN_0011aed8() }while(0)`).
2. **Re-init** the RPC layer (`FUN_00115300(0)`, `FUN_0011a188`, `FUN_00116cb8`, `FUN_00119aa8`,
   `FUN_001010a8(0)`, `FUN_00101c38(2)`).
3. **Open the IOP image** (`do{ fd = FUN_00116cf0(0x244ef0, 1) }while(fd < 0)`), obtain its size
   (`FUN_001170f8(fd,0,2)`), rewind, allocate/prep a `0x1000000`-based buffer (`FUN_00117330`,
   `FUN_00116f78`), and wait for the load buffer (`do{ buf = FUN_00119b30(size) }while(buf==0)`).
4. **DMA** the image to IOP RAM: `FlushCache(0)`, `sceSifSetDma(&dmadesc, 1)`, poll `sceSifDmaStat`
   until complete. `dmadesc = { dst=0x1000000, src=size, len=buf, 0 }` [decompiler field order].
5. **Relocate**: for `iRam01000004` entries starting at `0x1000008` (stride 8), add the load address
   `buf` to each pointer word (`*p += buf`).
6. **Start modules**: walk `DAT_00244e30` (stride-3 records, `-1` terminated); for each, if id `== 10`
   call `FUN_0012a748(1,2)` first, then register/start the module
   `FUN_001a21c0(0x1000000, id, arg1, arg2)`.
7. **Finish**: `FUN_00119c98(buf)` (release), `FUN_001b4930()`, `FUN_00183c90(0x244f10,0x10,0x244f30,0)`
   (final bind/init).

## Side effects
- Reboots/reinitialises the IOP and its RPC transport.
- Loads and relocates an IOP RAM image at base `0x1000000` (relocation patches `iRam01000004` words).
- Starts the module set described by `DAT_00244e30`.

## Important branches
- Init handshakes spin (`while (lVar2 == 0)`) until each subsystem is ready.
- Image open spins `while (lVar2 < 0)` until the file opens.
- DMA poll spins `while (-1 < lVar4)` until `sceSifDmaStat` reports done.
- Relocation loop bounded by `iRam01000004` (count embedded in the image header at `0x1000004`).
- Module loop terminates at the `-1` sentinel; id `== 10` triggers the `FUN_0012a748(1,2)` pre-step.
