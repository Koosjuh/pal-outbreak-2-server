## Behavioral explanation
The clear/free counterpart to `record_pool_reserve` (`FUN_001ab460`). Given the base pointer of a reserved run (`param_1`), it finds the pool slot whose ptr-table entry equals `param_1` (linear scan, ≤100). If found **and** its size is non-zero, it zeroes the run's backing memory (`size * 0x98` bytes, 0x98 = 152-byte record stride) and clears the slot's type tag to 0 (marking the slot empty). Note: it does **not** decrement `count`/`used` or shift later entries — it wipes the data and voids the type but leaves the arena high-water mark and pool length untouched (a soft free, not a compaction).
