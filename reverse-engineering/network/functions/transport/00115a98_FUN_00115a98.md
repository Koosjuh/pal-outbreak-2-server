## Behavioral explanation
EE-side **SIF RPC bind** stub. It binds a client-data block (`param_1`) to an IOP RPC server
identified by `param_2`. It allocates a request node from the SIF pool `0x25e440`, links the node to
the client-data block bidirectionally, stashes the target server number into the node, then issues
SIF request `0x80000009` (the BIND command) to the IOP. In synchronous mode it blocks on a semaphore
until the IOP replies with the resolved server handle; in async mode it fires-and-returns.

This is the standard `sceSifBindRpc` shape: `param_1` is the client-data struct that later
`sif_rpc_call` (FUN_00115c68) and the readiness predicate (FUN_00115e60) operate on.

## Input / output
- `param_1` (`int *`) — client-data block to initialise. Layout touched:
  - `[0]` = request-node ptr, `[1]` = node's server-id slot (`node+0x18`), `[2]` = semaphore
    (or -1 async), `[4]` = 0 (cleared), `[9]` = 0 (cleared).
- `param_2` — target IOP server number / RPC id (written to `node+0x20`).
- `param_3` (`ulong`) — mode flags. **bit0 = ASYNC** (no semaphore, no wait).
- Returns `undefined4`:
  - `0` success,
  - `0xFFFFFFFF` (-1) node alloc failed,
  - `0xFFFFFFFD` (-3) semaphore create failed,
  - `0xFFFFFFFE` (-2) SIF dispatch failed.

## Side effects
- Allocates a request node (pool 0x25e440); on failure paths frees it (FUN_00115570).
- Writes node fields: `+0x14`=self, `+0x1c`=client block, `+0x20`=server id.
- Sync path: creates then deletes a semaphore around the request.

## Important branches
- `lVar3 == 0` (alloc fail) -> return -1.
- `(param_3 & 1) == 0` (SYNC): CreateSema; if `< 0` -> free node, return -3; else dispatch cmd
  0x80000009; if dispatch == 0 -> free node + DeleteSema, return -2; else WaitSema + DeleteSema,
  return 0.
- `(param_3 & 1) != 0` (ASYNC): `param_1[2] = -1`; dispatch; if dispatch == 0 -> free node, return
  -2; else return 0 immediately (caller polls readiness via FUN_00115e60).

## Constants & flags
- `0x80000009` — SIF request selector = **BIND** (bit31 set marks a system/RPC command).
- `0x40` — dispatch mode/priority argument to FUN_00115088 (shared with the CALL stub).
- `param_3 & 1` — ASYNC flag.

## Corrected reconstruction
```c
// EE-side sceSifBindRpc equivalent. Returns 0 on success, negative errno on failure.
enum { SIF_ASYNC = 1 };                 // param_3 bit0
#define SIF_CMD_BIND 0x80000009u

int sif_rpc_bind(sif_client_t *cd, u32 server_id, u32 flags)  // param_1, param_2, param_3
{
    cd->w4 = 0;                         // param_1[4]
    cd->w9 = 0;                         // param_1[9]

    sif_node_t *node = sif_node_alloc(0x25e440);  // FUN_001154c8
    if (node == NULL)
        return -1;                      // 0xffffffff

    cd->node   = node;                  // param_1[0]
    cd->srv_id = node->server_id;       // param_1[1] = *(node+0x18)
    node->cmd_arg = server_id;          // node+0x20 = param_2
    node->self    = node;               // node+0x14
    node->client  = cd;                 // node+0x1c

    if (!(flags & SIF_ASYNC)) {
        cd->sema = CreateSema(&(sema_t){.init=1,.max=0});   // param_1[2]
        if (cd->sema < 0) { sif_node_free(node); return -3; }

        if (sif_dispatch(SIF_CMD_BIND, node, 0x40, 0,0,0) == 0) {   // FUN_00115088
            sif_node_free(node);
            DeleteSema(cd->sema);
            return -2;
        }
        WaitSema(cd->sema);
        DeleteSema(cd->sema);
        return 0;
    } else {
        cd->sema = -1;
        if (sif_dispatch(SIF_CMD_BIND, node, 0x40, 0,0,0) == 0) {
            sif_node_free(node);
            return -2;
        }
        return 0;                       // async: readiness via FUN_00115e60
    }
}
```
