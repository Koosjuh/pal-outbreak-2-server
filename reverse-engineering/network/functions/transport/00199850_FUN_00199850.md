## Behavioral explanation
Returns the **effective element count** of the TLV record resolved by `FUN_001999e0()`. The record's
raw count lives at word `[1]` (`+0x04`). If the record's flag word `[0]` (`+0x00`) has bit `0x80000000`
set, the effective count is `count - 1` — i.e. the high-bit marks that the last/first slot is reserved
(sentinel, self-entry, or terminator) and should be excluded from the caller-visible count.

This is a member of the tagged-record (TLV) accessor family whose record shape is
`{ u32 type/flags@+0, u32 count@+4, u32 field8@+8, u32 payload[]@+0xc }` (shared with
`FUN_001998c0`, `FUN_00199d50`, `FUN_00199df0`, `FUN_0019a260`).

## Corrected reconstruction

```c
struct tlv_record {
    u32 type_flags;   // +0x00  bit31 (0x80000000) => reserved slot
    u32 count;        // +0x04
    u32 field8;       // +0x08
    u32 payload[];    // +0x0c
};

uint record_effective_count(void)
{
    struct tlv_record *r = record_ctx_current();  // FUN_001999e0
    uint n = r->count;                            // r[1]
    if (r->type_flags & 0x80000000)               // r[0] high bit
        n -= 1;                                   // exclude reserved slot
    return n;
}
```
