## Behavioral explanation
Fills a caller-supplied set of out-parameters describing the current network adaptor / link state.
`piRam0035c3d8` is the pointer to the active interface descriptor published by the adaptor bring-up
`FUN_001bf5e0` (which sets `uRam0035c3d8 = 0x35c3b8`). The function copies two descriptor shorts
(word index 2 and 3 of the descriptor), the low bit of `uRam0036d560` as a link-up/carrier flag, and —
only when the descriptor's state word (`*piRam0035c3d8`) is 2 or 3 (link established states) — queries
the live link record via `FUN_001eeb50` and returns `record.field / 100` as the last out-param
(a scaled link metric, e.g. speed or signal). When not established, that out-param is 0.

## Input / output
- **param_1** (`u16*` out): descriptor word[2] (config/id short).
- **param_2** (`u16*` out): descriptor word[3] (config/id short).
- **param_3** (`u16*` out): link-up flag = `uRam0036d560 & 1`.
- **param_4** (`u16*` out): scaled link metric (`record/100`) when state∈{2,3}, else 0.
- **Return:** void.

## Side effects
None on globals; writes the four out-params. `FUN_001eeb50` issues an SN@P RPC (selector 0x23) but is
a pure query.

## Important branches
- `*piRam0035c3d8 == 3 || *piRam0035c3d8 == 2` (link established) → call `FUN_001eeb50`, set
  `*param_4 = record.metric / 100`.
- otherwise → `*param_4 = 0` (already pre-set).

## Constants & flags
- Descriptor state values `2`, `3` = link-established states (evidence: the gated branch). Other values
  (e.g. the `0x21` type token written in `FUN_001bf5e0`) = not-established / different phase.
- `uRam0036d560 & 1` = carrier/link-up bit.
- `/100` scaling on the metric.
