## Behavioral explanation
An **event-driven stream-filter callback** over a small descriptor object (`param_3`, a word array). It accumulates up to **0x140 (320) bytes** in an internal buffer and forwards them to a byte sink, and drains a producer's bytes out to a transport fd. `param_1` selects the event; `param_2` is a length/argument. The 320-byte cap + byte-at-a-time sink forwarding is characteristic of a **line/header accumulator** in a text protocol stage (HTTP/DNAS-style framing) sitting between a raw transport (`stream_read`/`stream_write` on the fd) and a consumer sink.

## Input / output
- `param_1` : `int` event selector — `1`/`2` = feed (data-in / flush), `3` = drain (write out), `4` = end/close. (`< 1` → no-op; other → no-op.)
- `param_2` : `ulong` length: for feed events, bytes to append, or `0` = flush the accumulator.
- `param_3` : `u32*` stream descriptor (see field map below).
- **return** : void (errors are fatal via `net_panicf`).

## Important branches
- **event 3 (drain/write):** `stream_write(fd, buf[4], buf[1]&0xffff)`; on success advance `buf[4] += n`, `buf[1] -= n`, return. On error → panic `0x24fd60`, then `buf[3] = 0`.
- **event 1/2, `param_2 == 0` (flush):** if header length word `*(u16*)buf[5] > 0xc`, loop from offset 0xc copying each byte into the sink (`**(sink+0xc) = b; sink_putc(sink)`); then `buf[2] = 0`.
- **event 1/2, `param_2 != 0` (append):** bounds `buf[2] + param_2 <= 0x140` else panic `0x24fd20`; `stream_read(fd, buf[5]+buf[2], param_2&0xffff)`; on `<0` panic `0x24fd48`; `buf[2] += n`.
- **event 4 (end):** if `buf[1] != 0` (unconsumed residual) panic `0x24fd78`; then `buf[3] = 0`.
- default / `param_1 < 1` / `param_1` other → return.

## Constants & flags
- `0x140 (320)` — accumulator capacity.
- `0xc (12)` — header prefix skipped on flush (first 12 bytes are a length/type header; payload starts at +0xc).
- events `1/2` feed, `3` drain, `4` end.

## Corrected reconstruction

```c
typedef struct {
    int   fd;            // [0]
    int   drain_len;     // [1]
    int   fill;          // [2]
    int   state;         // [3]
    u8   *drain_cur;     // [4]
    u8   *accum;         // [5]  (cap 0x140)
    void *sink;          // [6]  ( *(sink+0xc) -> byte sink cursor )
} stream_desc; // [inferred]

void stream_filter_event(int ev, ulong arg, stream_desc *d)
{
    if (ev == 3) {                               // drain to transport
        long n = stream_write(d->fd, d->drain_cur, d->drain_len & 0xffff);
        if (n >= 0) { d->drain_cur += n; d->drain_len -= n; return; }
        net_panicf(FMT_write_err);               // 0x24fd60
    } else if (ev < 4) {
        if (ev < 1) return;                      // no-op events
        if (arg == 0) {                          // FLUSH accumulator to sink
            u16 *hdr = (u16*)d->accum;
            if (*hdr > 0xc) {
                for (int i = 0xc; i < (int)*hdr; i++) {
                    *(u8*)(*(u8**)((char*)d->sink + 0xc)) = ((u8*)hdr)[i];
                    sink_putc(d->sink);          // FUN_00113c50
                }
            }
            d->fill = 0;
            return;
        }
        if ((u32)(d->fill + (int)arg) > 0x140)   // overflow guard
            net_panicf(FMT_overflow);            // 0x24fd20
        long n = stream_read(d->fd, d->accum + d->fill, arg & 0xffff);
        if (n < 0) net_panicf(FMT_read_err);     // 0x24fd48
        d->fill += n;
        return;
    } else if (ev == 4) {                        // END
        if (d->drain_len != 0) net_panicf(FMT_residual, d->drain_len); // 0x24fd78
    } else return;
    d->state = 0;                                // reached by ev==4 and write-err path
}
```
