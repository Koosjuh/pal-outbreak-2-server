## Behavioral explanation
Loads an asset either by **slot-derived filename** (`param_1 == 0`) or by **explicit key**
(`param_1 != 0`), then decompresses and uploads its blocks into a display slot and builds the display
structure. Two request-building branches feed a shared upload tail.

**Path A — `param_1 == 0` (auto by free slot):**
1. Allocate a free slot `slot = FUN_001cbc30()`; abort if `-1`.
2. Resolve the slot's resource string `s = FUN_001cc170(slot, param_3, 0, 0)`; abort if null.
3. Validate/measure it (`FUN_0010a050`); locate the last `'\\'` (0x5c) to strip the directory
   (`FUN_0010a6b0`); copy the basename (`FUN_00109eb8`, `+1` past the slash); truncate at `'.'`
   (0x2e) to drop the extension; append the suffix `0x23ae78`.
4. Send the constructed name on **channel A** (`FUN_001a0df0(name, base)`); set `param_3 = slot`.

**Path B — `param_1 != 0` (explicit key):**
- Abort if `param_3 == -1`.
- If `(param_4 & 0x10000) == 0`: format `fmt@0x23ae88` with `0x23ae10` + `param_1` and send on
  **channel B** (`FUN_001a0e90`).
- Else (`0x10000` set): format `fmt@0x23ae80` with `param_1,param_1` and send on **channel A**
  (`FUN_001a0df0`).

**Shared upload tail — reply length `> 0`:**
- Copy a **0x30-byte reply header** (`FUN_001069a8`), activate the target slot `FUN_001cbc20(param_3)`.
- If `hdr.off_2c != 0`: iterate `hdr.count_24` blocks; each block is length-prefixed
  (`len = *blk`), LZ-decompress the payload `blk+1` (`FUN_001a79b0`) into `base+0x180000`, upload it
  to the rolling slot `param_3++` (`FUN_001cba30`), advance `blk` by `len+4`. Then `FUN_001841d0`.
- If `hdr.off_1c != 0 && hdr.off_c != 0`: build the display structure
  `FUN_001ce2d0(param_2, param_4 & 0x7fffffff, base+off_1c, base+off_c, 0)` and flush.

Domain: **asset/graphics streaming loader** (sibling of `FUN_001a0eb0`), not lobby protocol.

## Input / output
- `param_1` (long) — asset key/name; `0` ⇒ derive filename from a freshly allocated slot.
- `param_2` (ptr) — display-structure template/target passed to `FUN_001ce2d0`.
- `param_3` (int) — target slot id (Path B); overwritten with the allocated slot in Path A;
  `-1` = invalid ⇒ abort in Path B.
- `param_4` (ulong) — flags + mode: bit `0x10000` selects request format/channel; low 31 bits
  (`param_4 & 0x7fffffff`) are the mode passed to `FUN_001ce2d0`.
- Returns `void`.

## Reply header layout (0x30 bytes @ `auStack_30`)
| local | field | meaning |
|---|---|---|
| `iStack_2c` | off_2c | offset to block list (0 ⇒ no blocks) |
| `iStack_24` | count_24 | number of length-prefixed blocks |
| `iStack_1c` | off_1c | display-structure source A |
| `iStack_c`  | off_c  | display-structure source B |

## Side effects
- Path A allocates a display slot (`FUN_001cbc30`) and builds a temp filename on the stack.
- Uploads decompressed blocks into GS slots (`FUN_001cba30`), activates slot (`FUN_001cbc20`),
  flushes (`FUN_001841d0`), builds display structure (`FUN_001ce2d0`).

## Important branches
- Path A: `slot == -1` → return; `FUN_001cc170 == 0` → return; `FUN_0010a050 == 0` → return;
  no `'\\'` found (`FUN_0010a6b0 == 0`) → return.
- Path B: `param_3 == -1` → return; `param_4 & 0x10000` selects `0x23ae80`/channel-A vs
  `0x23ae88`/channel-B.
- Tail: reply `<= 0` → skip; `off_2c == 0` → no block loop; `off_1c && off_c` → build structure.

## Constants & flags
- `0x5c` `'\\'` (path separator, strip dir), `0x2e` `'.'` (strip extension).
- `0x30` — reply header size; `base + 0x180000` — decompress scratch page.
- `param_4 & 0x10000` — request-format/channel selector; `param_4 & 0x7fffffff` — mode to
  `FUN_001ce2d0` (top bit is a private flag, masked off before use).
- block record: `[u32 len][len bytes payload]`, stride `len + 4`.
