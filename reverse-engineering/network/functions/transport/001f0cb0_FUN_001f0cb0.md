## Behavioral explanation
Synchronous SN@P-IPC stub that issues library call **fno 0x3b** carrying a single 16-bit argument.
It writes the argument to tx+0x1c, performs the blocking `sceSifCallRpc` round-trip (send 0x22 /
recv 0x20), and returns the u16 reply status. This is the "set one scalar attribute" shape of the
snap_req_* family (compare the 0x3a blob-setter and the 0x3c query).

## Input / output
- `param_1` — `u16` value to send (stored as the low half of tx+0x1c). Its semantic (a mode / flag /
  small id for SN@P attribute 0x3b) is IOP-side.
- **Returns** `u16` reply status from RX+0x18.

## Side effects

- Blocking SIF RPC to the IOP SN@P module (fno 0x3b); overwrites shared RX buffer.
- Acquires/releases the SN@P IPC mutex (serialises with the whole family).
