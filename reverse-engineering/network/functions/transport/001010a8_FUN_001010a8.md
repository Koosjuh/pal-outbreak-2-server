## Behavioral explanation
Master **init / terminate** entry for the whole net-RPC subsystem. Binds the **control service 0x80000592** (client `0x25bc28`), records the calling thread as the RPC owner, resets every per-service bound-flag to "unbound" (`0xffffffff`), then sends a single 4-byte **mode word** (`param_1`) and reads a 0x10-byte reply. The reply carries a service-availability code and two sub-status words that are decoded into a coarse return (1 = ok, 2 = degraded/partial). When `param_1 == 5` it takes the **teardown** path: releases resources (`net_rpc_teardown`) and invalidates the three service semaphore handles; otherwise (init modes) it unlocks via `net_rpc_lock`/`net_rpc_unlock_all`.

## Input / output
- `param_1` : `s32` mode/command. Observed decode: `5` = terminate; other in-range values = init/query. (The guard `((p<0)||(p<2))||(p!=5)` selects the "not the 5-terminate" branch — i.e. teardown runs **only** when `param_1 == 5`.)
- **return** : `0` on RPC failure or thread-ensure failure; `1` ok; `2` degraded (a sub-status word's high bits `< 2`).

## Side effects
- Sets `uRam0025ba18 = GetThreadId()` (RPC owner), `DAT_002074a4 = 1` (busy), bumps `DAT_002074d4` (generation).
- Resets bound-flags to `-1`: `DAT_002074c0/c4/bc/cc/c8/d0`; `DAT_002074b8 = 0`.
- Binds & waits control service ready (`iRam0025bc4c != 0`), latches `DAT_002074d0 = 0`.
- `sif_rpc_call` control fno with the mode word; clears busy `DAT_002074a4 = 0`.
- Teardown path (mode 5): `net_rpc_teardown()`, then `DAT_002074a8 = DAT_002074ac = DAT_002074a0 = 0xffffffff` (invalidate semaphores).
- `DAT_2020868c == 0xfe` → sets `ram0x00207490 = 1` (enable debug verbosity).

## Important branches
- `rpc_thread_ensure2(1) != 0` → return 0 (subsystem down).
- bind-spin control service 0x592 until ready.
- `sif_rpc_call < 0` → `DAT_002074a4 = 0`, return 0.
- reply avail code `DAT_2020868c`: `0xff` = fully ok (skip); `0xfe` = enable debug; else inspect sub-status `DAT_20208684` / `DAT_20208688` — if either's `>>8 < 2`, downgrade return to `2`.
- `param_1 == 5` → teardown + invalidate semaphores; else → `net_rpc_lock()/net_rpc_unlock_all()` (normal init release).

## Constants & flags
- `0x80000592` — control service id.
- mode `5` — terminate/shutdown.
- reply avail `0xff` ok / `0xfe` ok+enable-debug / other = decode sub-status.
- return `0` fail / `1` ok / `2` degraded.

```c
// Master init/terminate for the EE net-RPC subsystem (control service 0x80000592).
// param_1 == 5 => shutdown; other values => init/query.
u32 net_rpc_init_term(int mode)
{
    if (rpc_thread_ensure2(1) != 0) return 0;
    sif_dma_sync(0);

    g_rpc_owner_tid = GetThreadId();                  // uRam0025ba18
    g_rpc_busy      = 1;                              // DAT_002074a4
    g_rpc_generation++;                               // DAT_002074d4
    svc_bound_59a = svc_bound_597 = svc_bound_595 =
    svc_bound_593 = svc_bound_59c = ctrl_bound = -1;  // c0,c4,bc,cc,c8,d0
    g_rpc_flag_b8 = 0;

    while (1) {                                        // bind control svc, wait ready
        while (sif_rpc_bind(&ctrl_client, 0x80000592, 0) < 0) {
            if (dbg) net_tracef(FMT_ctrl_bind_retry, rc, g_rpc_generation);
            delay_spin(0x100000);
        }
        if (ctrl_client.server_ready != 0) break;     // iRam0025bc4c
        delay_spin(0x100000);
    }
    ctrl_bound = 0;                                   // DAT_002074d0

    ctrl_cmd_word = mode;                             // iRam0025bc80
    dcache_wb(&ctrl_cmd_word, 4);
    long rc = sif_rpc_call(&ctrl_client, 0, 0,
                           &ctrl_cmd_word, 4, ctrl_reply/*0x208680*/, 0x10, 0);
    if (rc < 0) { g_rpc_busy = 0; return 0; }

    u32 ret = 1;
    u8 avail = ctrl_reply.avail;                       // DAT_2020868c
    if (avail != 0xff) {
        if (avail == 0xfe) {
            dbg = 1;                                   // ram0x00207490
        } else {
            if (asr8(ctrl_reply.sub0) < 2 ||           // DAT_20208684
                asr8(ctrl_reply.sub1) < 2)             // DAT_20208688
                ret = 2;                               // degraded
        }
    }
    g_rpc_busy = 0;

    if (mode != 5) {                                   // init release
        net_rpc_lock();
        net_rpc_unlock_all();                          // FUN_001007c0
    } else {                                           // terminate
        if (dbg) net_tracef(FMT_teardown);
        net_rpc_teardown();                            // FUN_00100648
        sema_A = sema_B = sema_ctrl = 0xffffffff;      // invalidate handles
    }
    return ret;
}
```
