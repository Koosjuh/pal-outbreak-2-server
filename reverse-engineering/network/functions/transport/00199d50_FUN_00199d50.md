## Behavioral explanation
Reads a variable-length list out of the tagged-record tree and copies it into a caller u16 buffer as a
**count-prefixed u16 array**. Steps:
1. Resolve a container node via `FUN_00199f70(param_2, param_3)` and require its type word `== 4`
   (the container/list node type). If not type 4 ⇒ return `-1`.
2. Look up the child record for tag `0x100000` under that node (`FUN_0019a350(node, 0x100000, 0)`).
   If absent ⇒ return `-1`.
3. Read `n = record->count` (`+0x04`) and `payload = record + 0xc`. Write `out[0] = (u16)n`, then
   `out[1..n] = (u16)payload[i]` — truncating each 32-bit payload word to 16 bits.
4. Return `0` on success.

So `param_1[0]` receives the element count and `param_1[1..n]` the list values (each a u32 narrowed to
u16). Tag `0x100000` names *which* list is extracted.

## Input / output
- **Param 1** (`param_1`, `u16*`): output buffer; `[0]=count`, `[1..count]=values`.
- **Param 2, Param 3**: container-node selector for `FUN_00199f70`.
- **Return:** `undefined4` — `0` on success; `0xffffffff` (`-1`) if the node is not type 4 or the
  `0x100000` record is missing. (On the missing-record path `param_1` is left untouched.)

## Important branches
- `if (*(int*)node != 4) return -1;` — wrong node type gate.
- `if (record == 0) return -1;` — tag `0x100000` not present.
- `for (i=0; i<n; i++) out[i+1] = (u16)payload[i];` — copy/narrow loop; `uVar2` is set to `0`
  inside the loop init so an empty list (n==0) still returns 0 with only `out[0]=0` written.

## Constants & flags
- `4` — required container-node type (`node->type`).
- `0x100000` — TLV tag selecting the list record. (Sibling tags: `0xf0000` in `FUN_00199df0`,
  `0x50000` in `FUN_0019a210`/`FUN_0019a260`.)
- `+0x04` count, `+0x0c` payload; output is a count-prefixed u16 array.
- `0xffffffff` — failure return.

## Corrected reconstruction
```c
#define NODE_TYPE_CONTAINER 4
#define TLV_TAG_LIST_100000 0x100000

int tlv_read_u16_list_tag100000(u16 *out, node_sel a, node_sel b)
{
    struct tlv_node *node = tree_resolve(a, b);          // FUN_00199f70
    if (node->type != NODE_TYPE_CONTAINER)               // *(int*)node != 4
        return -1;

    struct tlv_record *r = node_find_or_load(node, TLV_TAG_LIST_100000, 0); // FUN_0019a350
    if (r == NULL)
        return -1;

    int n = r->count;                                    // *(int*)(r+4)
    u32 *payload = r->payload;                            // r+0xc
    out[0] = (u16)n;                                      // count prefix
    for (int i = 0; i < n; i++)
        out[i + 1] = (u16)payload[i];                     // narrow u32 -> u16
    return 0;
}
```
