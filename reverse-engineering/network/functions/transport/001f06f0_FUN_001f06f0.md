## Behavioral explanation
SN@P transport RPC stub for opcode **0x29**. Unlike its siblings it writes its argument to the **base**
of the send buffer (`A+0x00`, `0x37cf00`) rather than the `+0x1c` request-field region — i.e. it
overwrites the first header word. Its wrapper `FUN_001eee30` then advances the SNAP state-machine phase
variable `0x37a288 := 2`. Paired conceptually with op0x2a (`snap_rpc_op2a_phase5`, FUN_001f07a0) which
advances the same phase var to 5.

## Input / output

  `FUN_001f06f0()` with an uninitialised arg register), so in practice this word is don't-care /

- **Returns** (u16): IOP status word from `B+0x18`.

- Phase var `0x37a288` set to 2 by the caller wrapper (not here).
