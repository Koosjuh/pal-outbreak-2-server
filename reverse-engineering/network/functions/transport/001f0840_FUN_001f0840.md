## Behavioral explanation
SN@P transport RPC stub for opcode **0x2c = room EXIT** — the counterpart to op0x2b room ENTER
(FUN_001f07f0). Parameterless. Its wrapper `FUN_001ef070` clears the in-room flag `0x37a2a6 := 0` after
the call (and itself returns 0, discarding the stub's status). This is the transport-level room leave;
relevant to the known "exit-room stall" parking-lot item.

## Input / output
- **Inputs:** none.
- **Returns** (u16): IOP status word from `B+0x18` (discarded by the wrapper).

## Side effects
- `WaitSema`/`SignalSema` on `0x37aee0`; overwrites shared buffers A/B; blocks on the RPC.
- Caller clears `0x37a2a6 := 0` (no-longer-in-room).

## Important branches
None. The wrapper does not check the status — it clears the flag and returns 0 unconditionally.

## Constants & flags
- Transport fno `0x2c`. `ssize=0x20`, `rsize=0x20`. Status at `+0x18`.
- In-room flag: `0x37a2a6` (op2b → 1 enter, op2c → 0 exit).

## Corrected reconstruction

```c
// SN@P transport RPC stub — opcode 0x2c: ROOM EXIT (leave the current room). Pair: op2b enter.
// Wrapper FUN_001ef070 clears g_in_room (0x37a2a6) = 0 and returns 0.
u16 snap_room_exit(void)
{
    snap_ipc_lock();                                       // WaitSema(0x37aee0)
    snap_ipc_call_rpc(0x2c, SEND_A, 0x20, RECV_B, 0x20);   // header-only EXIT
    u16 status = *(u16*)(RECV_B + 0x18);                   // 0x37bf18
    snap_ipc_unlock();                                     // SignalSema(0x37aee0)
    return status;
}
```
