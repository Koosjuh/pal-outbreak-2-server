## Behavioral explanation
Looks up one entry (`param_3` = index) of the resource/section table selected by key `param_2`, and,
if that entry is a **type-4** record, fills the caller's output struct `param_1`. It first binds the
table to the key (`FUN_0019a2f0(param_2)`), bounds-checks the index against the entry count
(`*(section+4)`), fetches the entry pointer (`FUN_00199f70(param_2, param_3)`), reads the entry's
leading **type tag** (`*entry`), and dispatches on it. Only type 4 is handled: it stores a 16-bit
attribute at `outrec+0x20` and delegates to `FUN_0019abf0(outrec, entry)` to copy the rest. Types
8/7/6/3 and any other value fall through to a `0` (unsupported) return.

## Input / output
- `param_1` (ptr) — **out**: output record; `+0x20` (u16) receives the type-4 attribute; the body is
  written by `FUN_0019abf0`.
- `param_2` (key/handle) — selects which table/entry set to read.
- `param_3` (uint) — entry index; must be `< count`.
- Returns `undefined8`: for type 4, the result of `FUN_0019abf0`; otherwise `0` (out of range,
  missing entry, or unsupported type).

## Side effects
- `FUN_0019a2f0(param_2)` binds/pre-selects the active table for `param_2`.
- On the type-4 path: `*(u16*)(param_1 + 0x20) = FUN_0019a210(param_2, param_3)` and the record body
  is filled by `FUN_0019abf0`.

## Important branches
- `FUN_0019a350() == 0` → return 0 (section unavailable).
- `param_3 >= *(section+4)` (index ≥ count) → return 0 (out of range).
- `FUN_00199f70(param_2,param_3) == 0` → return 0 (entry pointer missing).
- `*entry == 4` → fill `param_1` (attr at +0x20, body via FUN_0019abf0), return that result.
- `*entry ∈ {8,7,6,3}` → return 0 (recognized-but-unsupported kinds; explicit arm).
- else → return 0 (unknown kind).

## Constants & flags
- Entry type tag = first word of the entry (`*entry`): value **4** = the supported record kind;
  **8/7/6/3** = enumerated unsupported kinds (given a dedicated but no-op branch); [inferred] these
  are a small `resource_entry_type` enum whose exact meanings are not yet mapped.
- `+0x04` of section = entry count (matches `FUN_0019a260`/`FUN_0019a210`).
- `param_1 + 0x20` (u16) = type-4 attribute slot in the output record.
