**Callees:** FUN_001bf1b0 (buffer reset/clear), FUN_00106a58 (memmove).

## Behavioral explanation
Drains bytes from the front of the EE-side **stream-buffer object** and compacts the remainder to the
start of the data region. `param_2` = number of bytes to consume; when `param_2 < 1` it defaults to
the current read cursor (`+0x04`), i.e. "consume everything already read". It computes the surviving
tail `remaining = filled_len - param_2`:
- If nothing survives (`remaining < 1`), the buffer is fully reset via `FUN_001bf1b0`.
- Otherwise the tail is `memmove`d down to `data_base` (offset +0x08), `filled_len` is set to
  `remaining`, and the read cursor is reset to 0.

This is the classic "advance past N consumed bytes and shift the rest to the front" stream compaction,
called after a parser has finished with the leading bytes returned by `FUN_001bf170`.

## Input / output
- **Param 1** (`int` buf): stream-buffer object (fields: +0x04 read cursor, +0x08 data base, +0x0c filled).
- **Param 2** (`int`): byte count to consume; `<1` ⇒ use the read cursor value.
- **Return:** void.

## Side effects
- Writes `buf+0x0c` (filled_len ← remaining) and `buf+0x04` (read_cursor ← 0) on the compaction path.
- `memmove` overwrites the data region with the surviving tail.
- On the empty path, delegates to `FUN_001bf1b0` (full reset).

## Important branches
- `param_2 < 1` → `param_2 = read_cursor` (default: consume the already-read prefix).
- `remaining = filled_len - param_2`:
  - `remaining < 1` → `FUN_001bf1b0(buf)` (reset; no memmove).
  - `remaining >= 1` → `memmove(base, base+param_2, remaining); filled_len = remaining; read_cursor = 0`.

## Constants & flags
- `FUN_00106a58(dst,src,len)` = engine `memmove`/`memcpy` (down-shift within same region ⇒ memmove).
- `FUN_001bf1b0(buf)` = buffer reset (zeroes cursor/filled). [inferred from empty-tail path]

## Corrected reconstruction

```c
// consume `n` bytes from the front of the stream buffer and compact the tail
void streambuf_consume_compact(streambuf *buf, int n)   // struct as in FUN_001bf140
{
    if (n < 1)
        n = buf->read_cursor;                 // default: drop everything already read

    int remaining = buf->filled_len - n;
    if (remaining < 1) {
        streambuf_reset(buf);                 // FUN_001bf1b0 — nothing left, full reset
    } else {
        memmove(buf->data, buf->data + n, remaining);   // FUN_00106a58
        buf->filled_len  = remaining;
        buf->read_cursor = 0;
    }
}
```
