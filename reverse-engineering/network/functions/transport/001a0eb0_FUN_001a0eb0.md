## Behavioral explanation
Streams an asset selected by a **3-byte key** (`param_1..param_3`) from the request channel and
uploads its decompressed sub-blocks into a texture/display slot, then builds the display structures.
Sequence:
1. Format a request string from the triplet (`FUN_00109728(buf, fmt@0x23ade0, p1,p2,p3)`).
2. Send on channel A (`FUN_001a0df0(buf, iRam003435bc)`); proceed only if reply length `> 0`.
3. Copy a **0x50-byte reply header** into a local (`FUN_001069a8`), and flip the double-buffer
   parity bit `bRam005a9048`.
4. For each of `count = *(base + hdr.off_4c)` sub-blocks: fetch it (`FUN_001a0a50`), LZ-decompress
   into a scratch page at `base+0x180000` (`FUN_001a79b0`), and upload/register it at a rolling GS
   slot `iVar4` (`FUN_001cba30`), where `iVar4` starts at `parity*0x80 + 0x1800`.
5. `FUN_001841d0()` flush; `FUN_001cbc20(parity*0x80 + 0x1800)` activate the slot band.
6. Allocate `uRam004de3a8 = FUN_001ab460(0x80, 6)`, build a structure via
   `FUN_001ce2d0(0x4ddba0, 2, base+hdr.off_3c, base+hdr.off_2c, 0)`, then mark `uRam004de3b2`
   records valid (`0x4de3e0[i] = 1`).
7. **Optional second asset** (if `hdr.off_1c != 0`): activate a second slot band
   (`parity*0x30 + 0x2100`), program a batch of draw/GS registers via `FUN_001a7b70` (0x15,1,0x12,
   0x62,0xc,0x66,2 — the `0x66` gets value 1, others 0), allocate `uRam003f99cc = FUN_001ab460(0x400,7)`,
   and build the second structure `FUN_001ce2d0(0x3f91c4, 2, base+hdr.off_1c, base+hdr.off_c, 0)`.

Domain: this is an **asset/graphics streaming loader**, not a lobby-protocol function — it rides the
same request channel used by the netstack but its payload is compressed texture/geometry data.

## Input / output
- `param_1, param_2, param_3` (u8 each) — the 3-part asset key formatted into the request.
- Returns `void`. Effects are the uploaded slots + built display structures + allocations.

## Side effects
- Toggles `bRam005a9048` (frame/double-buffer parity).
- Uploads decompressed blocks into GS slot bands (`FUN_001cba30`/`FUN_001cbc20`).
- Allocates `uRam004de3a8` (0x80×kind6) and `uRam003f99cc` (0x400×kind7); zeroes the paired
  `uRam004de3b8`/`uRam003f99dc`.
- Writes valid flags into `0x4de3e0[0..uRam004de3b2)`.
- Programs draw/GS registers via `FUN_001a7b70` on the 2nd-asset path.

## Important branches
- reply length `<= 0` → return immediately (no asset).
- sub-block loop runs `count` times (count from `*(base+off_4c)`); `iVar4` slot index increments per
  block.
- `iStack_1c != 0` → load/build the optional second asset + register batch; else skip.

## Constants & flags
- `0x50` — reply header size copied locally.
- `base + 0x180000` — LZ-decompress scratch page.
- slot band A base `parity*0x80 + 0x1800`; slot band B base `parity*0x30 + 0x2100`.
- `FUN_001ab460(0x80,6)` and `FUN_001ab460(0x400,7)` — allocations; `6`/`7` = pool/kind selector.
- structure templates `0x4ddba0` (A) and `0x3f91c4` (B); `FUN_001ce2d0(..., 2, ...)` mode `2`.
- `FUN_001a7b70` register batch `{0x15,1,0x12,0x62,0xc,0x66,2}` with `0x66←1`, rest `←0` — GS/draw
  mode setup for the 2nd asset.

// Stream the asset identified by the 3-byte key, decompress its sub-blocks into GS slots,
// then build the display structures. Optionally loads a 2nd asset when hdr.off_1c is set.
void asset_load_by_triplet(u8 k0 /*param_1*/, u8 k1 /*param_2*/, u8 k2 /*param_3*/)
{
    int base = iRam003435bc;                  // work base
    char req[256];
    FUN_00109728(req, /*fmt*/0x23ade0, k0, k1, k2);

    long n = asset_request_chanA(req, base);  // FUN_001a0df0
    if (n <= 0) return;

    struct asset_hdr *h;                      // 0x50-byte reply header
    FUN_001069a8(&h, base, 0x50);             // memcpy header out of the reply
    bRam005a9048 ^= 1;                        // frame parity
    int scratch = base + 0x180000;
    int *blk = (int*)(base + h->off_4c);      // block list; blk[0] = count
    int count = *blk++;
    int slot  = bRam005a9048 * 0x80 + 0x1800;
    for (int i = 0; i < count; i++, slot++) {
        FUN_001a0a50(uRam0029bc20, *blk++, scratch);  // fetch compressed sub-block
        FUN_001a79b0(scratch, (void*)scratch);        // LZ decompress in place page
        FUN_001cba30((void*)scratch, slot);           // upload/register to GS slot
    }
    FUN_001841d0();                                    // flush
    FUN_001cbc20(bRam005a9048 * 0x80 + 0x1800);        // activate slot band

    uRam004de3a8 = FUN_001ab460(0x80, 6);              // alloc record pool A
    uRam004de3b8 = 0;
    FUN_001ce2d0(0x4ddba0, 2, base + h->off_3c, base + h->off_2c, 0); // build struct A
    FUN_001841d0();
    for (int i = 0; i < (int)uRam004de3b2; i++)
        *(u8*)(0x4de3e0 + i) = 1;                       // mark records valid

    if (h->off_1c != 0) {                              // optional 2nd asset
        FUN_001cbc20(bRam005a9048 * 0x30 + 0x2100);
        FUN_001a7b70(0x15,0); FUN_001a7b70(1,0);  FUN_001a7b70(0x12,0);
        FUN_001a7b70(0x62,0); FUN_001a7b70(0xc,0); FUN_001a7b70(0x66,1);
        FUN_001a7b70(2,0);                             // GS/draw register batch
        uRam003f99cc = FUN_001ab460(0x400, 7);         // alloc record pool B
        uRam003f99dc = 0;
        FUN_001ce2d0(0x3f91c4, 2, base + h->off_1c, base + h->off_c, 0); // build struct B
    }
}
