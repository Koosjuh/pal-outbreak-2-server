## Behavioral explanation
Arms the deferred-dismiss request: sets `kbd+0x31 = 1`. This flag is polled each frame by kbd_close_if_flagged (637180), which on seeing it clears it (637250) and tears the keyboard down. Splitting "request" from "act" lets the layout/open code (006345e0) schedule a close that the shared per-frame hook actually performs, avoiding re-entrancy during layout rebuild.
