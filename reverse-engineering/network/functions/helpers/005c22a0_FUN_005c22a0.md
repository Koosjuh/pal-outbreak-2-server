## Behavioral explanation
**NOTE: the prior record ("8-byte thunk") was wrong** — this function is 156 bytes and is the
**room-commit / channel-open state-machine arm**. Guarded by once-flag 0x6cbb6c, on first call it:
1. **memset(0x6cdbe6, 0, 0x460)** — clears the 0x28-stride roster table (ready for repopulation).
2. Sets the channel-commit flags **0x6ce5ce = 1, 0x6ce5cf = 1, 0x6ce5d0 = 1**.
3. Raises the **scenario/cast unlock gate 0x6ff2b1 = 3** (the create pump had set it to 1; this is
   the second stage that fully unlocks title/pw/scenario/char — see MEMORY `g12-room-registry-layer`,
   "0x6ff2b1 1→3").
4. Installs pump `FUN_005c1c80` at 0x6cbb48, resets step 0x6cbb68 = 0, and stores the completion
   callback `param_1` at 0x6cbb4c.
Returns 0 on arm, -1 if already armed.

The pump `FUN_005c1c80` runs a multi-step **3-channel commit**: it queries channels via
`FUN_005bf1e0(2/1/0)`, opens/commits them with `FUN_005c0750` / `FUN_005bfe00`, and at the terminal
step tears them down with either `FUN_005bf180(0,1,2)` (mode `0x70047c==0`) or `FUN_005bf130(0,1,2)`
(otherwise), clears the lobby/in-game mode flag 0x70047c, then fires the callback with status 0x00
(success) or 0xFF (state 5, failure).
