## Behavioral explanation
Zero-argument keyword handler that delegates entirely to FUN_005edc40, the row measure/layout routine.
FUN_005edc40 dispatches on the current field-type selector `cfg+0x4e4` (a switch 0..7) to compute a
width `sVar7`:
- type 0/1: width = `cfg+0x4e6` (default 16 if zero) — the fixed field width set by 0x005e9580.
- type 2..5: width = `cfg+0x4e6`, or if zero, the multibyte-aware character count of the caption at
  `cfg+0x3e4` (the string set by 0x005e9540).
- type 6: optionally rebuilds a derived string via FUN_005d9dd0 (guarded by flags 0x186/0xe96b), then
  falls through to type 7.
- type 7: width = `cfg+0x6ec` (numeric set by 0x005e96d0).
It then feeds the width into the text-measure path (FUN_005ed6e0, updating `cfg+0xd8bc..0xd8c4` and
possibly the panel-max width `cfg+0x182`), or into FUN_005f2940 when the alternate-render flag
`cfg+0xd892` is set. This handler therefore commits/measures the current menu row after its attributes
have been parsed.

## Input / output
- No parameters used (`void`). Returns `0`.

## Side effects (via FUN_005edc40)
- Reads field-type `cfg+0x4e4` and the previously-parsed width/caption fields.
- Updates measure outputs `cfg+0xd8bc/0xd8be/0xd8c0/0xd8c4`; may raise panel width `cfg+0x182`
  (only when `cfg+0x186 == -10 (0xF6)`).
- type 6 path may synthesize `cfg+0x2e4` from `cfg+0x3e4` via FUN_005d9dd0.

## Important branches
- All branching is inside FUN_005edc40 (the `switch(cfg[0x4e4])`); see that record. Unknown selector
  values hit `default` and return without measuring.

- `cfg+0x186 == 0xF6 (-10)` gates the panel-width update.
