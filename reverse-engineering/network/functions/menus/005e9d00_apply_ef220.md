## Behavioral explanation
Markup tag handler that opens a new text-style scope. It is a thin trampoline to `FUN_005ef220`,
the style-stack **push**: `FUN_005ef220` clamps the current style depth `+0x124` to <= 0xe, copies
the current top-of-stack size/indent (`+0x128`) and color/attr (`+0x168`) into the next row — unless
a pending named override was stashed (`+0x2c3` int via `FUN_005ec4f0`, `+0x2d3` byte via
`FUN_005ec800`, e.g. from `markup_attr_read_style2d3`) — then increments the depth and re-applies
the active color via `FUN_005ec100`. Net effect: `<b>`/`<size=...>`-style scope open.

## Input / output

## Side effects
- Increments style-stack depth `g_markup+0x124` (saturating at 0xe).
- Populates the new style row (`+0x12c` int, `+0x169` byte) from the current top or the pending
  named-attribute overrides `+0x2c3`/`+0x2d3`.
- Re-latches the active render color via `FUN_005ec100`.

## Important branches
All in `FUN_005ef220`:
- `+0xd892` table-mode flag selects the color source (`+0x17c` global vs. per-cell `+0x252f`).
- If `+0x124 > 0xe` -> clamp to 0xe (max nesting).
- If pending int-attr string `+0x2c3` is empty OR `FUN_005ec4f0` returns < 0 -> inherit parent's
  `+0x128`; else store the parsed int.
- If pending byte-attr `+0x2d3` empty -> inherit parent's `+0x168`; else store resolved byte.
- If `+0x124 < 0xe` -> depth += 1.
